# NOCAP: 유튜브 가짜뉴스 판별 확장 프로그램 (Zero-Cost Edition)

## 💡 현재 상황 (Current Status)
현재 NOCAP 스펙(v1.1)은 외부 서버 없이 **100% 온디바이스(크롬 내장 브라우저 환경)** 에서 구동되는 하이브리드 판독망 시연 단계입니다.

* **실시간 자막 추출**: 유튜브 화면 내 자막 텍스트 실시간 파싱 완료 (API Key 불필요)
* **2단계 Gatekeeper 필터링**: '뮤직비디오', '게임', '예고편' 감지 시 즉각 AI 스킵 및 패스 (배터리 및 리소스 소모 획기적 절감)
* **로컬 Veto(거부권) 시스템**: 수백 개의 사이비/음모론 키워드 자체 내장. 포착 즉시 AI 결과와 무관하게 페널티 및 강제 신뢰도 강등 구현 완료
* **환각 방지 (위키백과 RAG)**: Service Worker 백그라운드를 통해 위키백과 데이터 Fetch 후 프롬프트에 주입하여, 오정보 환각 완벽 차단
* **Chrome Summarizer API 연계**: 초경량 추론을 위해 긴 텍스트를 `window.ai.summarizer`로 선행 압축하는 모듈 연동 완료
* **원인 추적 UI (판독 근거)**: 모든 가산점 및 감점 사유를 Shadow DOM 환경의 팝업 UI에 명확히 표출

## 🔮 향후 계획 (Future Plans)
현재의 텍스트·맥락 기반 기술을 넘어서, 더욱 입체적이고 수익성 있는 플랫폼으로 거듭나기 위해 다음 파이프라인 개발을 준비 중입니다.

* **딥페이크(Visual) 시각 분석 엔진 탑재 엔진 도입**
   - HTML5 `<canvas>`를 통해 영상 프레임을 분할 취득
   - WebGL/WebGPU 지원 경량 ONNX 모델을 로드해 눈 깜빡임 빈도 등 딥페이크 여부 실시간 스캔 판별
* **채널 평판 점수(Graph) 교차 검증 시스템**
   - 유튜버의 과거 허위 사실 유포 이력 및 채널 공신력을 누적 평가하여 판독 가중치 적용
* **프리미엄 결제(라이선스) 연동 모델링**
   - 보다 상세한 심층 분석 리포트 기능과 사이비 선동 영상 자동 스킵 기능을 묶어, Stripe / Toss API를 활용한 라이센스 키 월정액 판매 적용 예정
