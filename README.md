# NOCAP: 유튜브 가짜뉴스 판별 확장 프로그램 (Zero-Cost Edition)

유튜브 영상의 신뢰도를 실시간으로 판별하는 크롬 확장 프로그램입니다. 본 프로젝트는 사용자의 비용 부담과 개인정보 노출을 최소화하기 위해 **100% 온디바이스(On-device) AI 및 로컬 분석** 기술을 사용합니다.

---

## 🚀 왜 NOCAP인가? (핵심 가치)
*   **Zero-Cost (비용 0원)**: 별도의 백엔드 서버 연동이나 과금이 발생하는 유료 API(ChatGPT 등)를 전혀 쓰지 않습니다! 개발/유지 비용이 '0'원에 수렴합니다.
*   **Privacy-First (개인정보 보호)**: 유튜브 시청 기록, 자막, 데이터가 사용자의 컴퓨터(브라우저) 밖으로 단 한 글자도 빠져나가지 않고 내부에서 즉시 처리 후 폐기됩니다.
*   **Edge AI (온디바이스)**: 최신 크롬(Chrome) 브라우저에 내장된 AI 엔진(`window.ai` / Gemini Nano)을 활용하여 로컬에서 지능적으로 분석합니다.

---

## 💡 현재 구현된 기능 (Current Capabilities) 

NOCAP은 v1.6 업데이트를 통해 서버 없이도 강력한 하이브리드 판독망을 구축했습니다.

1. **실시간 자막 추출 (No API Key)**
   - 유튜브 DOM의 MutationObserver를 활용해, YouTube Data API 권한/할당량 없이 현재 화면에 재생되는 핵심 자막만 읽어옵니다.
2. **2단계 Gatekeeper 필터링 (리소스 최적화)**
   - 1차: 순수 자바스크립트로 영상의 제목 등을 검사해, '뮤직비디오', '게임', '예고편' 같은 신뢰도 분석이 불필요한 콘텐츠는 즉시 통과시켜 무거운 추론을 아예 끕니다. 
   - 2차: AI 분석이 필요한 정보성/정치/이슈 영상에만 Gemini Nano 모터를 가동하여 **노트북 배터리 소모와 발열을 획기적으로 해결**했습니다.
3. **로컬 번들 사이비/음모론 검색기 (Veto System)**
   - 허경영, 신천지, 켐트레일, 백신 칩 등 **글로벌 극단주의 & 유사과학 사전**이 내장되어 있습니다. 해당 패턴 발견 시, AI의 실수(환각)와 관계없이 강제로 신뢰도 점수를 20점 이하로 박살 내는 거부권 로직이 구현되어 있습니다.
4. **브라우저 내장 요약기 (Summarizer)**
   - 분량이 방대한 자막을 다짜고짜 AI에 넣어 토큰이나 메모리가 터지는 것을 막기 위해, `window.ai.summarizer`로 선행 압축(Sliding compression)하여 추론 속도를 2배 이상 높였습니다.
5. **서버 없는 RAG 연동 (Wikipedia Open API)**
   - 영상의 핵심 키워드로 `background.ts` 서비스 워커를 통해 위키백과를 호출(CORS 우회)합니다. 신뢰성 높은 백과사전 데이터를 로컬 AI의 프롬프트에 주입하여, 오직 지능(AI)만 브라우저 것을 쓰고 지식(DB)은 외부의 공인된 무료 지식을 끌어다 쓰는 하이브리드 모델을 완성했습니다.
6. **상세한 "판독 근거" UI 제공**
   - 왜 이런 점수가 나왔는지(예: 과도한 느낌표 사용, 뉴스 포맷 가산점, Veto 거부권 발동 등) 세세한 근거를 Shadow DOM 위젯 화면으로 유려하게 띄웁니다.

## 🔮 앞으로 개발해야 할 내용 (Future Roadmap)

현재 모델은 '텍스트 맥락'을 위주로 훌륭하게 작동하지만, 완전한 진위 판별 서비스로 발돋움하기 위해 다음의 마일스톤이 계획되어 있습니다.

### 1. 딥페이크(Visual) 시각 분석 엔진 탑재
*   **영상 프레임 스크래핑**: HTML5 `<canvas>`를 통해 현재 재생 중인 유튜브 영상의 특정 프레임을 초당 1장씩 캡처합니다.
*   **On-device 비전 검증**: WebGL/WebGPU를 활용하는 경량화된 오픈소스 딥페이크 탐지 모델(ONNX)을 브라우저에 배포하여 눈 깜빡임 빈도, 입술 픽셀 깨짐 등을 검사해 $S_{visual}$ 점수를 도입합니다.

### 2. 채널 신뢰도 데이터베이스(Graph) 구축
*   현재는 제목과 자막 구조만 봅니다. 하지만 채널의 과거 이력(예: 과거에 가짜 뉴스로 신고 당한 횟수, 극단적 유튜버인지 인증 여부)을 평가하는 평판 점수($S_{source}$)를 퍼블릭 오픈 데이터베이스 등과 연결하여 더 정교하게 가중치를 매깁니다.

### 3. 수익화 (NOCAP Premium Licensing)
*   지속 가능한 업데이트를 위해, 분석 심도 조절(Logic/Evidence 심층분석)과 유해 광고/선동 영상 스킵 기능을 묶어 **Stripe 또는 Toss API를 활용한 라이선스 키 판매 모델**을 도입할 계획입니다. 서버는 결제 인증용으로만 가동되며 분석은 여전히 제로코스트 원칙을 지킵니다.

## 💻 Tech Stack
*   **Language**: TypeScript
*   **Build Tool**: Vite + CRXJS
*   **Local AI**: Chrome Built-in AI (Gemini Nano via `window.ai.languageModel` & `window.ai.summarizer`)
*   **UI System**: Shadow DOM (유튜브 기존 테마와 격리된 디자인 보장)
